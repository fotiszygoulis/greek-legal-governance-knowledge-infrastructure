# Corpus

This folder contains the first working legal-governance corpus for the AGRIR-Lab component **Greek Legal-Governance Knowledge Infrastructure for AI and Institutional Research**.

## Current corpus groups
- 01_core_normative_corpus
- 02_institutional_reconfiguration
- 03_delegations_and_decision_flows
- 04_financial_administrative_architecture
- 05_cross_cutting_frameworks

## Purpose
The corpus is organized to support:
- institutional mapping
- competence tracing
- delegated authority analysis
- internal audit relevance
- financial-administrative architecture analysis
- resilience-oriented governance research

## Status
This is the first pilot corpus structure and will be expanded gradually.
