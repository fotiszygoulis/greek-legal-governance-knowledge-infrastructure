# Cross-Document Layer Model v1

## Scope
This file captures the first layer-based model of the first six documents processed in the pilot corpus.

## Layer 1 — Organizational Baseline
### Core document
- PD 4/2018

### Function
- original organizational baseline of the Ministry
- central and regional architecture
- institutional distribution of services and units

## Layer 2 — Secretariat Reconfiguration
### Core document
- PD 84/2019

### Function
- internal secretariat restructuring
- separation between heritage governance and contemporary-culture governance
- support-function repositioning closer to the Minister

## Layer 3 — Operational Resource Management
### Core document
- Law 4761/2020

### Function
- ODAP operational role
- ticketing, retail, publications, digital applications, property, and visitor services
- operational exploitation layer within the cultural-governance system

## Layer 4 — Substantive Heritage Protection
### Core document
- Law 4858/2021

### Function
- substantive legal framework of heritage protection
- monuments, archaeological sites, museums, access, anti-trafficking, and criminal protection
- core legal environment of cultural heritage governance

## Layer 5 — Museum Reform and Governance Amendments
### Core document
- Law 5021/2023

### Function
- museum NPDD reform
- state indemnity for mobility of cultural goods
- ODAP amendments
- broader governance amendments affecting the heritage system

## Layer 6 — Competence Boundary Reset
### Core document
- PD 77/2023

### Function
- separation of culture governance from sports governance
- renaming of the Ministry
- removal of the sports branch from the Ministry of Culture competence perimeter

## First Layer Model Insight
The pilot corpus is already structured as a layered governance model rather than a flat legal collection.
The first six documents collectively build:
- an organizational base,
- an internal secretariat structure,
- an operational resource-management layer,
- a substantive heritage-protection layer,
- a museum reform layer,
- and a final competence-boundary reset layer.

## Analytical Use
This layer model can support:
- structured legal interpretation
- institutional architecture analysis
- reform-sequence analysis
- competence tracing
- later visual diagrams and OSF methodological notes
