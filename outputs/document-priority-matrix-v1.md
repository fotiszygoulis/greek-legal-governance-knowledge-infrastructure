# Document Priority Matrix v1

This file records the first document-priority matrix for the AGRIR-Lab component **Greek Legal-Governance Knowledge Infrastructure for AI and Institutional Research**.

| Priority Tier | Document Group | Description | Immediate Use |
|---|---|---|---|
| Tier 1 | Ministry organization and heritage code | Core normative and structural documents defining the Ministry and the heritage protection regime | institutional mapping, competence mapping, legal grounding |
| Tier 1 | ODAP and museum governance reform | Core governance documents for supervised entities, museum restructuring, and cultural resource administration | supervised entities analysis, governance mapping |
| Tier 1 | Delegations and decision flows | Documents defining transferred authority, signature powers, and regional decision competence | approval-flow mapping, traceability analysis |
| Tier 1 | Internal audit and accountability | Documents establishing or operationalizing internal audit and control functions | oversight mapping, accountability layer |
| Tier 2 | Institutional reconfiguration | Documents reflecting structural changes across ministries, general secretariats, and administrative hierarchies | transition analysis, restructuring logic |
| Tier 2 | Financial-administrative architecture | Documents clarifying budgeting, procurement, payroll, and supervised-entity support structures | administrative support mapping |
| Tier 3 | Cross-cutting resilience frameworks | Horizontal governance and resilience-related framework laws | comparative governance and resilience analysis |

## Current Status
- This is the first working priority matrix.
- The next version will connect each tier to specific document IDs from the document register.
- Later versions will distinguish between working priority, publication priority, and coding priority.
